MD5 Hash Algorithm

## Short Description
Interactive virtual lab to implement, trace and evaluate the MD5 Message-Digest Algorithm with 128-bit digest generation, avalanche effect analysis, and 64-round compression visualization.

## Input
Any UTF-8 text string of arbitrary length.

## Output
A fixed 128-bit (32 hexadecimal character) MD5 message digest.

## Theory Summary
MD5 is a cryptographic hash function (RFC 1321) that processes input in 512-bit blocks through four rounds of 16 operations using auxiliary functions F, G, H, I and produces a 128-bit digest via Merkle-Damgard construction. It is deprecated per RFC 6151 due to collision vulnerabilities.
