MD5 Hash Algorithm

Generate and analyze MD5 hash values for given input messages.

Aim

To generate the MD5 hash value for a given input message and analyze the effect of changing the input on the resulting hash value.

Objectives

  • Understand the basic working of the MD5 hashing algorithm.
  • Generate a 128-bit MD5 hash for a given message.
  • Understand how the input message is processed before hashing.
  • Observe the effect of changing the input message on the hash value.
  • Understand the importance of the avalanche effect in hashing.

Theory

MD5 (Message-Digest Algorithm 5) is a cryptographic hash algorithm that takes an input message of arbitrary length and produces a fixed length hash value of 128 bits. The resulting hash is commonly represented as a 32-character hexadecimal string. A hash function processes data in such a way that even a small change in the input produces a significantly different output.

Before the MD5 compression process begins, the input message is converted into bytes and prepared according to the MD5 preprocessing rules. A single binary 1 bit is appended to the message, followed by enough zero bits so that the message length becomes 448 bits modulo 512. The original message length, measured in bits, is then appended as a 64-bit value. As a result, the complete message becomes a multiple of 512 bits.

Each 512-bit block is divided into sixteen 32-bit words. MD5 maintains four 32-bit working registers, commonly represented as A, B, C and D. These registers are initialized with predefined values. The algorithm then processes each 512-bit block through 64 operations arranged into four rounds. Each round uses a different logical function to combine the current register values with message words and predefined constants. Bitwise operations and left rotations are used during these operations.

After all 64 operations for a block are completed, the resulting register values are added to the previous state. This process is repeated for every 512-bit block of the message. After the final block has been processed, the four 32-bit register values are combined to form the final 128-bit MD5 digest. The digest is displayed as a lowercase hexadecimal value.

An important property demonstrated in this experiment is the avalanche effect. When a small change is made to the input message, such as changing or adding one character, the resulting MD5 hash changes significantly. This makes it difficult to determine the original input simply by observing the hash. However, MD5 is no longer considered secure for modern cryptographic applications because practical collision attacks have been demonstrated. Therefore, this experiment focuses on understanding the working and properties of the algorithm rather than recommending MD5 for secure password storage or other modern security applications.

Procedure

  1. Open the MD5 Hash Algorithm experiment.
  2. Enter a message in the input field provided in the simulation.
  3. Run the MD5 hashing operation to generate the hash value.
  4. Observe the generated 128-bit MD5 hash represented as a 32-character hexadecimal string.
  5. Change the input message slightly, for example by adding, removing, or changing one character.
  6. Generate the hash again and compare the new hash with the previous result to observe the effect of changing the input.
