Section 2 • Theory

MD5 Algorithm - Theory

1. Introduction and Overview

The MD5 Message-Digest Algorithm is an iterated cryptographic hash function designed by Ronald Rivest of MIT in 1991 and specified in RFC 1321. MD5 processes an arbitrary-length message and produces a fixed-size 128-bit (16-byte) message digest, conventionally represented as a 32-character lowercase hexadecimal string.

Core Property: A cryptographic hash function is a deterministic one-way mapping. For any message M, computing MD5(M) is straightforward, but inverting the digest to find M is computationally intractable (preimage resistance).

2. Preprocessing and Padding (RFC 1321)

MD5 processes data in blocks of 512 bits (64 bytes, sixteen 32-bit words). Padding ensures the bit length satisfies:

Length (bits) ≡ 448 (mod 512)

Padding is performed in four deterministic stages:

  1. Append Padding Bits: A single '1' bit (byte 0x80) is appended directly after the message payload.
  2. Append Zero Bits: Between 0 and 511 zero bits (0x00 bytes) are added until message length is 64 bits short of a multiple of 512.
  3. Append Length: A 64-bit representation of the original message length (in bits, modulo 2^64) is appended in little-endian byte ordering.
  4. Block Division: The padded sequence is partitioned into N consecutive 512-bit blocks (M[0], M[1], ..., M[N-1]).

3. Four 32-Bit Working Registers

MD5 maintains an internal state consisting of four 32-bit registers (A, B, C, D) initialized to standard constants (RFC 1321):

Register A0x67452301
Register B0xefcdab89
Register C0x98badcfe
Register D0x10325476

4. Four Nonlinear Compression Rounds

Each 512-bit block undergoes 64 operations organized into 4 rounds of 16 operations each. Each round utilizes a unique bitwise auxiliary function:

Round Auxiliary Function Mathematical Formulation Operation Range
Round 1 F(X, Y, Z) (X & Y) | (~X & Z) Steps 0 to 15
Round 2 G(X, Y, Z) (X & Z) | (Y & ~Z) Steps 16 to 31
Round 3 H(X, Y, Z) X ^ Y ^ Z Steps 32 to 47
Round 4 I(X, Y, Z) Y ^ (X | ~Z) Steps 48 to 63

The step transformation formula updates the registers via:

A = B + ((A + Function(B, C, D) + X[k] + T[i]) <<< s)

where X[k] is a 32-bit sub-block of the message, T[i] is floor(2^32 × |sin(i + 1)|), <<< s is circular left rotation, and + denotes addition modulo 2^32.

5. Merkle-Damgard Feed-Forward Accumulation

After completing all 64 step operations on block M[i], the resulting register values are added modulo 2^32 to the state prior to that block (feed-forward step):

A = (A + A_prev) mod 2^32; B = (B + B_prev) mod 2^32; C = (C + C_prev) mod 2^32; D = (D + D_prev) mod 2^32;

Once all N blocks are processed, the registers A, B, C, D are serialized in little-endian order to produce the final 32-character hexadecimal digest.

6. Security and Cryptanalytic Status

Deprecated: MD5 is no longer cryptographically secure. In 2004, Xiaoyun Wang et al. demonstrated practical collision attacks allowing two distinct inputs to produce identical hashes in minutes. Per RFC 6151 and NIST SP 800-131A, MD5 must NOT be used for digital signatures, certificates, or password hashing. Modern security requires SHA-256, SHA-3, or Argon2id/Bcrypt for passwords.
Section 3 • Procedure

Laboratory Procedure

  1. Initialize the Experiment: Navigate to the Simulation tab. The default test string abc is pre-loaded to verify against the RFC 1321 standard vector.
  2. Inspect the Digest Output: Observe the resulting 128-bit hexadecimal hash. For abc, the expected digest is 900150983cd24fb0d6963f7d28e17f72. Check the input bit count (24 bits) and 512-bit block count (1 block).
  3. Examine Message Padding: Switch to the Padding view inside the simulation. Inspect how the original bytes are followed by the 0x80 delimiter, zeros padded up to bit 448, and the 64-bit little-endian message length.
  4. Trace the Round Buffers: Switch to the Round State view. Observe the intermediate values of registers A, B, C, and D after Round 1 (F function), Round 2 (G function), Round 3 (H function), and Round 4 (I function).
  5. Evaluate the Avalanche Effect: Switch to the Avalanche Heatmap view. Modify a single character or bit in the input message and observe the live Hamming distance and bit diffusion percentage across all 128 bits.
